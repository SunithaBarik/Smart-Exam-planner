# 📚 Smart Exam Planner

An intelligent Python-based study planner that automatically generates a day-wise study schedule based on your exam date, subjects, and difficulty levels.

## 🎯 Problem Statement
Students often struggle to plan their exam preparation effectively. They don't know what to study, when to study, or how much time is left. This leads to last-minute stress and incomplete syllabus coverage.

## 💡 Solution
Smart Exam Planner solves this by:
- Calculating days remaining until the exam
- Prioritizing hard subjects first
- Reserving the last 3 days exclusively for revision
- Generating a structured day-wise study plan

## ✨ Features
- **Days Left Calculator** - Automatically calculates remaining days
- **Priority-Based Planning** - Hard subjects get higher priority
- **Today's Task Finder** - Shows exactly what to study today
- **Progress Dashboard** - Real-time tracking of completed vs pending days
- **Visual Progress Chart** - Bar chart using Matplotlib
- **Auto Export to CSV** - Saves the full plan for offline use

## 🛠️ Tech Stack
- Python
- Pandas - Data manipulation
- Matplotlib - Data visualization
- Datetime - Date calculations

## 🚀 How to Run
1. Clone this repository
2. Open `SmartExam planner.ipynb` in Jupyter Notebook
3. Update `EXAM_DATE` and `SUBJECTS` as per your exam
4. Run all cells to generate your personalized study plan

- Progress Dashboard: 12.5% Complete
- Progress Bar Chart: Done vs Pending
